Featured Capstone Project

HandAura

Bilingual Multi-Vendor Marketplace for Handmade Goods

Role: Team Leader • ITI Capstone

HandAura is a bilingual Arabic/English multi-vendor marketplace connecting customers with handmade product creators. The platform is built using a Clean/Onion Architecture and provides secure authentication, product and shop management, real-time buyer-seller communication, notifications, and payment integration.

Architecture & Engineering Highlights

5-layer Clean/Onion structure: Domain, Application, Infrastructure, API, MVC Admin.
Authentication: JWT + cookie-based, role-based authorization for customers & vendors.
Real-time buyer-seller instant messaging & event notifications via SignalR hubs.
Core e-commerce: shops, products, orders, seller balances modeled in SQL Server with EF Core.
Integrations: Paymob payment gateway, Cloudinary CDN media, and OTP verification.
Modern Angular 20 client built with standalone components and reactive Signals.
