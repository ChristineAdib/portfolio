# Christine Adib — Personal Portfolio Website

A warm, elegant, editorial, and fully responsive personal developer portfolio website for **Christine Adib**, Full-Stack .NET & Angular Developer.

Designed and built with Vanilla **HTML5, CSS3, and JavaScript** following the warm botanical, editorial elegance and earthy terracotta/forest green aesthetic:
- **Primary Background:** Warm Cream & Ivory (`#FBF8F3`)
- **Card Backgrounds:** Soft Beige (`#F5EFE6`) & Crisp White (`#FFFFFF`)
- **Forest Green Accents:** `#224335` (Active navigation pill, "Explore My Work" button, signature "Let's Connect!" organic wave banner)
- **Terracotta Accents:** `#C47A53` ("Let's Talk" button, "Get In Touch", heart badges, sparkle stars `✦`, project arrow buttons)
- **Editorial Typography:** High-contrast serif headings (`Playfair Display`), warm handwritten script (`Caveat`), and modern clean UI body text (`Plus Jakarta Sans`).

## 🚀 How to Run Locally

Open `index.html` directly in any modern web browser or start a local server:

```bash
# Using Python:
python -m http.server 8000

# Using Node.js:
npx serve .
```
